# CV project entry

**Quantitative Research Project — Intraday Futures Backtester**

Developed a Python backtesting framework for an intraday futures opening-range
strategy, implementing OHLC data validation, next-bar execution, configurable
slippage and commission modelling, conservative stop/target handling, and
chronological train/test reporting. Added risk statistics and a bootstrap
confidence interval for mean net R; tested execution edge cases with unit
tests. Clearly labelled synthetic sample data and documented model limitations.

**Tools:** Python, pandas, NumPy, Matplotlib, Git, unittest.
