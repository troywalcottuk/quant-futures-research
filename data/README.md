# Data

sample_1m_ohlc.csv is fully synthetic and generated by
scripts/generate_sample_data.py with a fixed random seed. It is a software
fixture, not historical exchange data and not evidence of a trading edge.

Columns: timestamp, open, high, low, close. Timestamps use
America/New_York local session time and include UTC offsets.

Trade-level journals with realized R outcomes but no intraday OHLC bars
cannot reconstruct price-level fills. No personal trade records are included.
